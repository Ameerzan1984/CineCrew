# CineMesh web workspace

The Next.js interface is a local demonstration of discovery and production workflows. Run it from this directory:

```sh
npm install
npm run dev
```

Open http://localhost:3000. `npm run build` checks the production build; `npm run lint` runs TypeScript checking.

Film titles, creators and images are illustrative demo content. Creating or editing a project and saving films use browser localStorage, not the film engine or a user account. The watch preview, director chat, collaboration, generation and provider connection require services that are not connected to this interface. No user credentials are collected. The interface is currently English-only; Arabic, authentication, API integration and production data are outstanding work.
